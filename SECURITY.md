# Security

## Supported versions

Security fixes are provided for the latest tagged release. This experimental
project does not currently promise a response-time SLA. Keep Go and the system
libusb package patched.

## Reporting a vulnerability

Use the repository's **Security** tab and select **Report a vulnerability** to
send a private report to the maintainers. Do not post exploit details,
credentials, device identifiers, or private recordings in a public issue.

Include the affected version, platform, likely impact, and a minimal synthetic
reproducer where possible. Malformed event streams and untrusted USB devices
are relevant inputs.
